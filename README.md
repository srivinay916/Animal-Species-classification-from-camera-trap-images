# 🐾 Animal Species Classification from Camera Trap Images

## 📌 Project Overview
This project focuses on building a deep learning-based image classification system to identify animal species from camera-trap images. It uses real-world wildlife data to analyze model performance under varying environmental conditions.

---

## 🎯 Research Questions
- Which deep learning models achieve the highest accuracy in classifying animal species?
- How does model performance vary across lighting, occlusion, and background complexity?
- Does image preprocessing and data augmentation improve classification performance?

---

## 📊 Dataset
- **Name:** Snapshot Serengeti Camera Trap Dataset  
- **Source:** LILA BC / Zooniverse  
- **Link:** https://lila.science/datasets/snapshot-serengeti  

### Description
- Collected in Serengeti National Park, Tanzania (2010–2013)  
- Captured using camera traps in natural environments  
- Annotated using expert validation and citizen science  

### Data Type
- **Input:** RGB Images  
- **Output:** Multi-class animal species labels
